# Bilateral acting: implementation and open acceptance

Animation `performance-2.2.9` adds independent rig-left and rig-right arm tracks. Gesture/action hand fields agree; omitted hand preserves the established rig-right default. Overlapping gestures are allowed on different arms, prohibited on the same arm. Gesture IDs remain unique across both tracks. Cue continuations are grouped per arm so an interleaved opposite-arm action does not restart a held gesture. Whole-actor idle owns neither arm; hand-specific idle owns only that arm.

The compiler solves and reports each hand separately. Gaze remains one attention channel; an authored plan chooses explicit attention when two hands have different targets. The bilateral seed otherwise lets the sampler prefer right-target attention, then left. This is rig-space naming, not certified anatomical hand mapping through turns/camera. Plans7/8 without new hand data remain parseable; version7 still rejects body/pole data, and version8 retains its body contract. New hand data requires version9.

Visualization events can require `contactActorId` and `contactHands`. Both required hands must belong to the same present performer, operate the correct part and contact before the event with matching action windows. Explicit contact gates also schedule the model-control response. Custom model `controlMode: none` suppresses the illustrative crank when the object is paper or another non-mechanical item. Primary completed placement may use either hand; a moving prop has one hand owner and one model binding. Production rejects duplicate model bindings, repeated placement, joint contact on a moving bound model, supporting attachment and cross-cut handoff. These unsupported motions remain open work, not approximated as successful scenes.
